Häufige Fragen

Die App verbindet sich nicht mit meinem Server

Prüfe folgende Punkte:

  • Sind Adresse (Host) und Port korrekt? Standard-Port ist oft 8080.
  • Ist der API-Schlüssel richtig? Du findest ihn in SABnzbd unter Einstellungen → Allgemein → API Key.
  • Bei aktivem SSL/HTTPS muss der Schalter in der App ebenfalls aktiviert sein.
  • Befinden sich iPhone und Server im selben Netzwerk? Von unterwegs brauchst du eine erreichbare Adresse (z. B. VPN oder Portfreigabe).
Wo finde ich meinen API-Schlüssel?

In der SABnzbd-Weboberfläche unter Einstellungen → Allgemein. Dort gibt es das Feld API Key. Kopiere diesen Wert und füge ihn beim Einrichten des Servers in der App ein.

Werden meine Daten irgendwo gespeichert?

Nein. Serveradressen und Einstellungen bleiben lokal auf deinem Gerät, der API-Schlüssel liegt sicher im iOS-Schlüsselbund. Es gibt kein Tracking und keine Cloud. Details in der Datenschutzerklärung.

Kann ich mehrere Server verwalten?

Ja. In den Einstellungen kannst du beliebig viele SABnzbd-Server hinzufügen, bearbeiten und zwischen ihnen wechseln.

Die Siri-Kurzbefehle funktionieren nicht

Stelle sicher, dass die App mindestens einmal gestartet und ein Server eingerichtet wurde. Die Befehle findest du in der Kurzbefehle-App oder per Siri, z. B. „Was lädt gerade?" oder „Pausiere SABnzbd Client".

Ich habe einen Fehler gefunden oder einen Wunsch

Super – schreib uns an kontakt@witting.info. Hilfreich sind: iOS-Version, App-Version und eine kurze Beschreibung, wie der Fehler auftritt.

Frequently asked questions

The app won't connect to my server

Please check the following:

  • Are the host address and port correct? The default port is often 8080.
  • Is the API key correct? Find it in SABnzbd under Config → General → API Key.
  • If SSL/HTTPS is enabled on the server, enable the toggle in the app as well.
  • Are your iPhone and server on the same network? Remote access needs a reachable address (e.g. VPN or port forwarding).
Where do I find my API key?

In the SABnzbd web interface under Config → General. Look for the API Key field, copy the value and paste it when setting up the server in the app.

Is my data stored anywhere?

No. Server addresses and settings stay locally on your device, and the API key is kept securely in the iOS Keychain. There is no tracking and no cloud. See the privacy policy for details.

Can I manage multiple servers?

Yes. In the settings you can add, edit and switch between as many SABnzbd servers as you like.

Siri Shortcuts aren't working

Make sure the app has been launched at least once and a server is set up. You'll find the commands in the Shortcuts app or via Siri, e.g. "What's downloading?" or "Pause SABnzbd Client".

I found a bug or have a request

Great — email us at kontakt@witting.info. It helps to include your iOS version, app version and a short description of how the issue occurs.
